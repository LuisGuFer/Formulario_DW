## Proyecto Formulario de Registro

## Descripción
Formulario web de registro desarrollado con HTML, CSS y JavaScript.

## Archivos
- index.html
- style.css
- script.js
- README.md

## Instalación y ejecución
1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar index.html en cualquier navegador web.

## Tecnologías usadas
- HTML5
- CSS3
- JavaScript
